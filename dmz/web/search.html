Statut de capture

Le trafic de recherche et les requêtes transitant vers ce serveur web sont interceptés en direct par Suricata et journalisés sous format standard eve.json.

Les alertes sont consultables en temps réel via l'interface EveBox, accessible depuis le réseau interne.

Exemples de requêtes

Requête Description
alert.signature:"ET SCAN" Toutes les alertes liées à un scan réseau
src_ip:172.20.0.* Événements provenant du sous-réseau DMZ
event_type:dns Requêtes DNS capturées
http.hostname:"web" Trafic HTTP vers le serveur web
