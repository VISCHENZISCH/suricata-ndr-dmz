Documentation de référence - NDR DMZ (Suricata + EveBox)

Projets & Outils complémentaires

  • PacketPhantom : outil CLI d'exploration, de capture et de manipulation de paquets réseau pour comprendre et tester le trafic bas niveau
  • ForensicTool : outil d'investigation numérique dédié à l'analyse d'artefacts et à la collecte de preuves techniques
  • SecurePipeline : outil CLI DevSecOps multi-stack, sécurisation des chaînes CI/CD et intégration automatisée des contrôles de sécurité applicative
  • Fileora View : interface web légère pour inspecter, prévisualiser et explorer des fichiers directement en ligne

Suricata (détection)

  • Documentation officielle (guide utilisateur) : installation, configuration, suricata.yaml
  • Écriture des règles : syntaxe, actions, options, threshold
  • Mots-clés HTTP : http.uri, http.user_agent, utiles pour les règles 1 et 2
  • Format de sortie Eve JSON : structure d'eve.json (alertes, stats, dns, http)
  • Sortie Eve JSON (configuration) : activer les types d'événements

EveBox (console d'alertes)

  • Dépôt GitHub d'EveBox : point d'entrée principal, avec le lien vers la documentation
  • Documentation d'exécution du serveur : lancement, entrée eve.json, authentification

Règles ET Open et mise à jour

  • Emerging Threats (Proofpoint) : jeu de règles ET Open
  • Documentation de suricata-update : télécharger et activer les règles

Docker, cibles et notifications

  • Docker Compose : syntaxe du fichier, réseaux, volumes, network_mode
  • Référence du fichier Compose : cap_add, read_only, security_opt
  • Mailpit : serveur SMTP de test pour les notifications e-mail
  • Grafana Alerting : alerting et dashboards, si Grafana est conservé
  • Nginx et PostgreSQL : conteneurs cibles

Outils de l'attaquant

  • Nmap : scans SYN (-sS) et de versions (-sV)
  • sqlmap : options d'utilisation, pour le scénario d'injection SQL

Conseils

  • Pour les règles personnalisées, partir des mots-clés HTTP et tester avec suricata -T -c suricata.yaml.
  • Pour l'image Docker de Suricata, partir de l'image officielle d'OISF ou de celle de Jason Ish (auteur d'EveBox), et vérifier leur page sur Docker Hub avant de fixer la version.

Remarque : Les liens Suricata et EveBox ont été vérifiés par recherche.
